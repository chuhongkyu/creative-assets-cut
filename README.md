# Creative Asset Studio

영상이나 이미지를 넣으면 **App Store** 소재 규격으로 잘라 내보내는 웹 도구.

Sticker Slime 광고 소재를 만들려고 시작했지만 게임과 무관하게 동작한다.

```bash
npm install
npm run dev     # http://localhost:3000
```

## 서버가 없다

**이 프로젝트에는 백엔드가 없다.** API 라우트도, 서버 함수도 없다.
영상 디코딩·크롭·재인코딩이 전부 브라우저 안에서 일어나고 파일이 밖으로 나가지 않는다.

`next.config.mjs`가 `output: "export"`라 정적 파일로만 빌드된다. Vercel은 호스팅만 한다.

### 왜 WebCodecs인가

브라우저에서 mp4를 만드는 방법은 셋인데 하나만 쓸 만하다.

| 방법 | 결과 | 왜 안 썼나 |
|---|---|---|
| **WebCodecs + mp4-muxer** | **mp4** | 쓰고 있는 것. 브라우저 하드웨어 코덱을 직접 부른다 |
| MediaRecorder | webm | Chrome이 webm만 내놓는다. Apple은 mp4/mov를 요구한다 |
| ffmpeg.wasm | mp4 | 30MB 다운로드 + SharedArrayBuffer용 COOP/COEP 헤더가 필요하다 |

WebCodecs는 **Chrome·Edge·Safari 16.4+**에서 동작한다. 지원하지 않는 브라우저면 카드에 경고가 뜨고 영상 내보내기 버튼만 막힌다.

## 규격

`src/lib/presets.ts` 한 곳에 모여 있다. 규격이 바뀌면 여기만 고치면 된다.

| 자리 | 크기 | 비고 |
|---|---|---|
| Universal | 1402 × 962 | 헤더와 검색 결과에 함께 쓴다. **하나만 만든다면 이것** |
| Product page header | 1646 × 661 | 제품 페이지 최상단 |
| Search results | 2168 × 1030 | 검색 결과 |

세 자리 모두 **영상과 이미지를 둘 다** 받는다. 규격마다 쓰고 싶은 소재가 다르기 때문에(헤더는 분위기, 검색은 한눈에 알아볼 장면) **자리별로 따로 올린다.**

> Google Ads 규격은 아직 넣지 않았다. 확정되기 전에 적어두면 틀린 값으로 소재를 만들게 된다.

> ⚠️ 이 치수는 Apple 공개 문서에 없다. Apple이 [디자인 템플릿](https://developer.apple.com/app-store/asset-best-practices/)(Figma/Photoshop/Pixelmator/Sketch)에만 넣어두었고, 위 값은 그 템플릿 캔버스에서 읽은 것이다. 템플릿이 갱신되면 확인이 필요하다.

## 맞춤 방식

**잘라서 채우기(cover)** — 목표 비율에 맞게 잘라낸다. 여백이 없는 대신 가장자리가 잘린다.
배경이나 풍경처럼 가장자리를 버려도 되는 소재에 쓴다. 세로로 자를 때 위·가운데·아래 중 어디를 남길지 고를 수 있다.

**전체 담기(contain)** — 원본을 통째로 담는다. 잘리지 않는 대신 여백이 생긴다.
로고나 캐릭터가 온전히 보여야 할 때 쓴다.

여백은 **단색 띠 대신 원본을 흐리게 깔아** 채운다. 띠는 광고에서 눈에 거슬리고, 흐린 배경은 원본 색감을 이어받아 자연스럽다.

## 원본 크기 주의

규격보다 작은 원본을 넣으면 확대되면서 흐려진다. 카드에 경고가 뜬다.

가장 큰 규격이 **2168 × 1030**이므로, 영상은 **긴 변 2200px 이상**으로 녹화해두면 모든 규격을 축소만으로 처리할 수 있다. 1280×720 같은 소스는 세 규격 전부에서 확대된다.

Unity 프로젝트라면 `com.unity.recorder`로 원하는 해상도를 직접 지정해 뽑을 수 있다.

## 소재 규정

App Store에 노출되는 소재는 **앱 등급과 무관하게 4+ 기준**을 만족해야 한다. 자산이 거부되는 가장 흔한 이유다.

Apple이 금지하는 것 중 게임에서 걸리기 쉬운 항목:

- 유혈·잔혹 묘사
- **사람이나 보는 사람을 향해 겨눈 무기**
- Editor's Choice, Apple Design Award 같은 Apple 선정 표식 (받지 않았다면 사용 금지)
- 검증 불가능한 수상 이력

자산 보관함(Asset Library)에 올리는 것과 실제로 노출되는 것은 다르다. 올린 뒤 **제품 페이지 헤더에 배정**하고, 지원하는 **모든 언어·지역에 현지화**해야 한다.

## 구조

```
src/
  app/page.tsx          규격 세 개를 세로로 쌓는다
  components/
    AssetSlot.tsx       규격 하나. 업로드 + 미리보기 + 설정 + 내보내기
  lib/
    presets.ts          규격 목록 ← 규격이 바뀌면 여기
    crop.ts             잘라내기 계산. 미리보기와 내보내기가 같은 함수를 쓴다
    exportImage.ts      캔버스 → jpg
    exportVideo.ts      WebCodecs → mp4
```

미리보기와 실제 내보내기가 **같은 `computeDrawRect`를 쓴다.** 보이는 것과 나오는 것이 어긋나지 않게 하려는 의도다.
